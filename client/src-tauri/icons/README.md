# Icons

Bundled icons live here. Replace these placeholders with branded artwork before
shipping a release. The set must include:

| File | Size |
|------|------|
| `32x32.png` | 32 × 32 |
| `128x128.png` | 128 × 128 |
| `128x128@2x.png` | 256 × 256 |
| `icon.icns` | macOS bundle icon |
| `icon.ico` | Windows bundle icon |

Generate them quickly with:

```bash
npm run tauri icon path/to/master-icon.png
```
